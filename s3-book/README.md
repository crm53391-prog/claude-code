# كراسة الطب S3

سيت شخصي على شكل كتاب لسيميستر 3: فهرس عام، صفحة لكل موديول، وصفحة لكل درس فيها
النوت والرأي ديالك (شنو صعيب، شنو ساهل، شحال من صعوبة).

## الملفات

| الملف | شنو كيدير |
|---|---|
| `page.html` | القالب: كامل الـ HTML/CSS/JS + placeholder وحيد `__DATA__`. **هنا كتبدل الديزاين والخاصيات.** |
| `modules.json` | المصدر الوحيد للموديولات/الأساتذة/الدروس. **هنا كتزيد ولا تبدل شي درس.** |
| `index.html` | الصفحة النهائية (مولّدة). هادي هي اللي كتتنشر كـ Artifact. ما تعدلهاش بيدك. |
| `build.py` | كيدمج `modules.json` فـ `page.html` وكيخرّج `index.html`. |

## إعادة البناء

```bash
python3 build.py
```

## الحفظ

الصفحة كتخدم بـ `db` capability ديال Claude Artifacts، يعني كلشي كيتسجل أوتوماتيك
فالسيرفر ديال الـ artifact وكيرجع معاك فأي جهاز:

| المسار | شنو فيه |
|---|---|
| `lessons/<module>-<nnn>` | `status` (0 باقية / 1 كنقرا / 2 خلّصت)، `diff` (1..4)، `note`، `hard`، `easy`، `mark` |
| `modules/m1..m6` | `opinion` — الرأي فالمادة كاملة |
| `meta/prefs` | `exam` (نهار الامتحان)، `last` (آخر درس تفتح) |

الـ id ديال الدرس كيتبنى من ترتيب الدروس فـ `modules.json` (`m2-015` = الموديول
الثاني، الدرس 15). إلا بدلتي الترتيب ديال الدروس، النوت القدام كيبقاو مربوطين
بالرقم القديم — زيد الدروس الجداد فالّخر ديال اللائحة باش ما يتخربقش والو.

ملاحظة: `index.html` مكتوب بالشكل اللي كيتسناه Claude Artifacts (بلا
`<!doctype>`/`<head>`، حيت المنصة كتزيدهم هي). إلا فتحتيه كملف عادي فالنافيغاتور،
غادي يبان الديزاين مي ما غاديش يتسجل والو حيت `window.claude` ما كاينش برا Claude.

## النشر

```
Artifact publish → file_path: s3-book/index.html, capabilities: {"db": {}, "user": {}}
```
نفس الـ URL كيتعاود استعماله ملي كتعاود تنشر نفس الملف.
